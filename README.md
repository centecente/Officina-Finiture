# Officina Finiture

Veste i pezzi di un prodotto audio con materiali e finiture reali (anodizzato, polvere RAL, ottone, legno, tessuto,
poliurea, plastica...), li mostra in 3D sotto luci diverse, confronta fino a quattro varianti, avvisa sui vincoli di
produzione e sui costi, ed esporta una scheda CMF per il cliente o per il fornitore. Carica i pezzi di Officina Manopole
e Officina Griglie (JSON) e qualsiasi STL.

Scarica `finiture-offline.html` dall'ultima Release e aprilo con doppio clic. Dettagli in `NOTE-PROGETTO.md`.
